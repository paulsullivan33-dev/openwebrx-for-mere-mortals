lab) performed the same exchange the web
page performs on ws://127.0.0.1:8073/ws/ :

     page's own javascript:
       -> "SERVER DE CLIENT
           client=openwebrx.js type=receiver"
       <- "CLIENT DE SERVER
           server=openwebrx version=v1.2.2"
     (Before this greeting the server answers
     nothing at all - "handshake is not
     complete" in its log.)

  3. selectprofile: the t04 device|profile
