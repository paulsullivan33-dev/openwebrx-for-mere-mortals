t01 - server start and first pages
The image filesystem was executed directly
(its own glibc loader + python3.9), with
/etc/openwebrx seeded from the image exactly
as docker/scripts/run.sh seeds it.

Startup log (tail):

    2026-10-22 23:44:40 - owrx.__main__ - INFO
      - OpenWebRX version v1.2.2 starting up...

First start notes, recorded honestly:
  * a one-time config migration ran
    ("config migration ... from version 1")
  * the log complained that the airspyhf and
    sdrplay sample devices were "not
    available" - their vendor services were
    not started in this lab. The rtl_sdr
    sample device reported the same until the
    connector tools were put on PATH;
    /api/features then reported rtl_sdr
    available (see t02).
